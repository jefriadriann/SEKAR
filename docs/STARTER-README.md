# SEKAR Dummy Starter

Paket INPUT untuk Codex/Claude Code, bukan aplikasi jadi.

1. Ekstrak ZIP ke folder proyek baru SEKAR.
2. Buka folder tersebut dengan Codex/Claude Code.
3. Copy seluruh isi METAPROMPT-CODEX-CLAUDE.md ke chat agent, atau minta agent membaca dan menjalankannya.
4. Jika ingin mengikuti referensi visual asli, tambahkan PDF referensi secara terpisah; PDF tidak disertakan dalam ZIP. Prompt sudah memuat spesifikasi enam halaman sehingga PDF opsional.
5. Agent membangun aplikasi demo tanpa akun Supabase. Ikuti README aplikasi yang dibuat agent untuk menjalankan hasilnya.

Semua unit KPw, uraian dan angka fiktif. Dataset berisi 46 KPw simulasi dan satu unit DR, 300 temuan (276 KPw + 24 DR), 96 permindok, 40 jadwal, 24 referensi, 12 kewajiban DR, dan 46 rekonsiliasi aset. Tanggal acuan 2026-10-05. Data ini bukan penilaian kantor BI mana pun.
